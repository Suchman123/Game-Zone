Game Zone is a responsive, multi-page esports and gaming web application designed from scratch. It serves as a digital platform for competitive gamers to register for competitions for trending esports titles Rocket League, Counter-Strike 2, League of Legends in Game Zone's e sports tournament The Weekend League while having community minigames.

The project demonstrates the practical integration of semantic HTML5, Bootstrap, JavaScript, and jQuery.

Structure
game-zone/
│
├── index.html          # Landing page (Home) with Bootstrap Carousel and highlights
├── games.html          # Game catalog exploration page
├── register.html       # Weekend League tournament registration form
├── rps.html            # Interactive Rock-Paper-Scissors Minigame page
├── main.css            # Custom styling overrides and dark-mode adjustments
├── validate.js         # Form validation and modal control logic
├── minigames.js        # jQuery-powered interactive minigame logic
└── images/             # Game screenshots and media assets
